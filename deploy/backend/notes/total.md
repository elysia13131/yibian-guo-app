# page_02
## 钙离子基础概述
- 人体最丰富的阳离子之一，99%存于骨骼，1%在血液与细胞内外
- 血钙组成：总钙 2.1-2.6 mmol/L，离子钙 1.1-1.3 mmol/L（生理活性形式）
- 来源：基础生理学、生物化学教材

# page_03
## 六大生理功能总览
1. 肌肉收缩——兴奋-收缩耦联关键桥梁
2. 神经传导——触发神经递质释放
3. 血液凝固——凝血因子IV
4. 信号转导——重要的第二信使
5. 骨骼构成与代谢——羟基磷灰石
6. 其他：膜稳定性、酶活性、凋亡、受精

# page_04
## 参与肌肉收缩
- 骨骼肌：Ca²⁺与肌钙蛋白C结合→暴露位点→横桥摆动
- 平滑肌：Ca²⁺+钙调蛋白→激活MLCK
- 心肌：钙诱导钙释放（CICR）
- 医学意义：钙通道阻滞剂（硝苯地平、维拉帕米）治疗高血压、心绞痛、心律失常

# page_05
## 参与神经传导与递质释放
- 动作电位→电压门控钙通道开放→Ca²⁺内流→囊泡融合→释放神经递质
- 与学习记忆相关的突触可塑性
- 临床：低钙→手足抽搐（Trousseau/Chvostek征）；高钙→肌无力、嗜睡

# page_06
## 参与血液凝固
- Ca²⁺作为凝血因子IV，激活几乎所有凝血因子
- 促进凝血酶原→凝血酶，纤维蛋白原→纤维蛋白
- 抗凝机制：枸橼酸钠螯合Ca²⁺，用于血库和凝血检测
- 临床：枸橼酸抗凝过量可致低钙凝血障碍

# page_07
## 信号转导与骨代谢
### 第二信使作用
- IP₃/DAG通路：激素→PLC→IP₃→ER释放Ca²⁺→钙调蛋白→CaMK
- 调控基因表达（NFAT等）
- 药物：环孢素、他克莫司（钙调神经磷酸酶抑制剂）
### 骨骼构成
- 羟基磷灰石储存99%钙
- 调节轴：PTH↑血钙，降钙素↓血钙，1,25-(OH)₂D₃促吸收

# page_08
## 血钙检测与临床诊断
- 总钙：比色法（邻甲酚酞络合酮法），正常2.1-2.6 mmol/L
- 离子钙：离子选择性电极法，正常1.1-1.3 mmol/L，受pH影响
- 高钙血症（>2.6）：甲旁亢、恶性肿瘤、VD中毒、结节病
- 低钙血症（<2.1）：甲旁减、VD缺乏、肾衰、胰腺炎

# page_09
## 高钙血症与低钙血症
### 高钙血症
- 病因：甲旁亢、恶性肿瘤（PTHrP）、VD中毒、制动
- 表现：乏力、恶心、多尿、神志模糊、QT间期缩短
- 治疗：补液+双膦酸盐+降钙素+原发病治疗
### 低钙血症
- 病因：甲旁减、VD缺乏、肾衰
- 表现：手足抽搐、喉痉挛、QT间期延长
- 治疗：口服/静脉补钙+活性VD

# page_10
## 钙代谢调节轴
- PTH：升血钙，促肾重吸收，活化VD
- 降钙素：降血钙，抑破骨
- 1,25-(OH)₂D₃：促肠钙吸收
- 相关疾病：骨质疏松、佝偻病、肾性骨病、甲旁亢/减

# page_11
## 钙剂在临床治疗中的应用
1. 补钙：骨质疏松、佝偻病、低钙血症（需联用维生素D）
2. 抗过敏：降低毛细血管通透性，辅助抗组胺（IV缓慢）
3. 心肌保护：对抗高钾血症（急救）、CCB中毒解毒
- 禁忌：洋地黄联用、心衰时慎用

# page_12
## 总结与关键要点
1. Ca²⁺不仅构成骨骼，更是生命活动的调控核心
2. 血钙平衡由PTH-维生素D-降钙素精密调控
3. 高钙危象：先补液后降钙；低钙抽搐：补钙+VD
4. 钙剂三大应用：补骨、抗敏、稳心
5. 临床警觉：心电图QT间期变化是血钙异常的镜子
- 思考题：为何补钙治骨质疏松，而CCB中毒时钙剂是解毒剂？
