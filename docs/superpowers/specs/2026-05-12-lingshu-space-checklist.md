## Phase 1 验收: 核心引擎

- [ ] **1.1** Three.js 场景正常渲染（地面 + 光照可见）
- [ ] **1.2** WASD 键移动正常，方向正确（W=前，S=后，A=左，D=右）
- [ ] **1.3** Shift 加速移动（1.5x 速）
- [ ] **1.4** 鼠标旋转视角流畅，PointerLock 点击锁定，ESC 解锁
- [ ] **1.5** 高度锁定在 1.6m，不会飞天/遁地
- [ ] **1.6** 碰撞检测有效，不会穿出场景边界
- [ ] **1.7** 至少 3 个占位角色渲染在场景中
- [ ] **1.8** 角色名字标签始终面向相机（billboard）
- [ ] **1.9** 灵枢角色有视觉区分（不同颜色/更大/光环）
- [ ] **1.10** 组件卸载时 3D 资源完全释放（无内存泄漏）
- [ ] **1.11** 页面切换（路由跳转）时场景正确销毁和重建
- [ ] **1.12** 浏览器窗口 resize 时场景自适应

## Phase 2 验收: 交互与对话

- [ ] **2.1** 靠近角色（<3m）时显示 "按 F 与 [角色名] 对话" 提示

- [ ] **2.3** 多个角色在场时，只对最近的角色显示提示
- [ ] **2.4** 按 F 键触发对话，打开对话面板
- [ ] **2.5** 对话面板显示角色名称和头像
- [ ] **2.6** 预设话题选项可见且可点击（3-5 个）
- [ ] **2.7** 自由输入框可用，Enter 发送，Shift+Enter 换行
- [ ] **2.8** 发送消息后显示 waiting 状态（加载动画）
- [ ] **2.9** AI 回复以流式方式逐字显示（打字机效果）
- [ ] **2.10** 回复完成时状态变为 completed
- [ ] **2.11** ESC 键关闭对话面板
- [ ] **2.12** 走远（>3m）自动关闭对话面板
- [ ] **2.13** 对话期间玩家移动锁定
- [ ] **2.14** 对话历史在面板内可滚动查看
- [ ] **2.15** 网络错误时显示友好提示和重试按钮
